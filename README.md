# 2D Graphics Editor

## Description
A menu-driven 2D Graphics Editor developed in C using a 2D character array.

## Features
- Draw Line
- Draw Rectangle
- Draw Circle
- Draw Triangle
- Display Picture
- Delete Area
- Clear Picture
- Modify Object

## Symbols Used
- '*' : Drawn Pixel
- '_' : Empty Space

## Canvas Size
80 x 24

## How to Run

Compile:

gcc main.c -o graphics

Run:

./graphics
